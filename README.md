# Plugins de NeumorStudio para Claude Code

Marketplace de plugins de Claude Code.

## Instalar

En Claude Code:

```
/plugin marketplace add NeumorStudio/claude-plugins
/plugin install cryptoagent@neumorstudio
```

En la app de escritorio: **Ajustes → Plugins → Añadir marketplace** con `NeumorStudio/claude-plugins`
y después instala el plugin desde **Descubrir**.

## Plugins

| Plugin | Qué hace |
|---|---|
| [cryptoagent](plugins/cryptoagent) | Agente autónomo de trading cripto en simulación: dinero ficticio con precios, liquidez y comisiones reales (Solana vía Jupiter, incluido pump.fun, y Binance). Misiones con capital, objetivo y plazo, memoria entre misiones y panel en directo. Funciona solo en Claude Code. Código fuente: [NeumorStudio/cryptoagent](https://github.com/NeumorStudio/cryptoagent). |

Los plugins de este repositorio se generan desde el repositorio de cada uno; no se editan aquí.
